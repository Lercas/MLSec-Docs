# Уведомление ФинЦЕРТ Банка России об инциденте в финансовой организации

> Рабочая заготовка сведений ФинЦЕРТ Банка России об инциденте с ИИ. Актуализация: 13.11.2026. Применимость определяется видом финансовой организации, затронутым процессом и конкретным требованием. Универсальные «3 рабочих часа + 72 часа» для всех финансовых AI-инцидентов не подтверждены и здесь не используются.

<a id="oblast_-primenenia"></a>

## Область применения

Следующие ситуации запускают квалификацию обязанности; сам пункт списка не доказывает обязательность подачи:
- Инцидент затронул автоматизированные системы, поддерживающие финансовые операции.
- Инцидент связан с ИИ-системой, участвующей в:
  - Кредитном / страховом скоринге
  - Антифроде
  - Дистанционном обслуживании клиентов (чат-боты, голосовые ассистенты)
  - Внутреннем аудите операций
  - Анализе рисков
  - Автоматических торговых решениях

## Канал подачи

Проверить действующие условия взаимодействия через АСОИ ФинЦЕРТ и резервный способ по [официальной странице Банка России](https://cbr.ru/information_security/fincert/). Конкретные схема, полномочия, подпись и квитанция определяются действующим каналом. Его закрытый регламент и настройки вашей организации здесь не проверены. Внутренний Markdown не является готовым сообщением АСОИ.

### 2.5. Первичные меры

- [ ] Kill-switch LLM Gateway активирован (уровень L0-L4).
- [ ] Ограничены операции по подозрительным каналам.
- [ ] Клиенты информированы о возможных ограничениях (если применимо).
- [ ] Служба комплаенса вовлечена.
- [ ] Проверены факты события по ст. 21(3.1) 152-ФЗ и применимость параллельного уведомления РКН.
- [ ] Проверены статус субъекта, объект / ресурс и событие по порядку 547, при применимости готовятся сведения НКЦКИ и ЦБ.

Отметки о выполненных мерах заполнять только по факту с временем и свидетельством. Незаполненный список не подтверждает активацию kill-switch, информирование клиентов или начало подготовки другого уведомления.

<a id="5-svazannye-uvedomlenia"></a>

## 5. Связанные уведомления

Если инцидент затрагивает несколько нормативных областей, обеспечивается параллельное уведомление:

- [ ] РКН по фактам и условиям ст. 21(3.1) — см. [RKN-152FZ.md](RKN-152FZ.md).
- [ ] НКЦКИ и дополнительный канал ЦБ по применимому объекту / событию — см. [GOSSOPKA-187FZ.md](GOSSOPKA-187FZ.md).
- [ ] Правоохранительные органы: адресат, основание, уполномоченный заявитель и содержание определены отдельно.
- [ ] Партнёры по платёжной системе: конкретный договор / правило / требование, срок и минимальный состав сведений.
