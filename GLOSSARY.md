<a id="glossarij"></a>

# Глоссарий

> Единый словарь терминов MLSec Recommendations: ИБ, ML, регуляторика, специфика LLM / агентов / RAG. Используйте как справочник при чтении методики и как основу для обучения команды.

<a id="a"></a>

## A

- **A2A (Agent2Agent)** - протокол взаимодействия агентов: discovery, сообщения, задачи и артефакты. Task/context ID помогает связать работу, но не является разрешением действовать от имени пользователя. См. [31](31-ai-agents-overview.md).
- **Action-bound approval** - согласие, связанное с конкретной операцией, её аргументами, субъектом, получателем и сроком; требует проверки при исполнении, отзыва и защиты от повторного использования. См. [33](33-ai-agents-security-overlay.md).
- **Adversarial attack** - целенаправленное воздействие на ИИ-систему; включает манипуляцию входом, данными, моделью, контекстом или окружением для достижения цели атакующего.
- **Adversarial training** - обучение модели на adversarial-примерах для повышения устойчивости.
- **Agent (AI agent)** - ИИ-система с автономным выполнением действий, использующая LLM + набор инструментов + планирование.
- **AI-BOM** - Artificial Intelligence Bill of Materials, описание состава и связей компонентов ИИ-системы. CycloneDX поддерживает такое представление; BOM связывают с реестром систем, владельцами и runtime, но он их не заменяет.
- **AIMS** - AI Management System, система менеджмента ИИ по ISO 42001.
- **ART** - Adversarial Robustness Toolbox (библиотека IBM для adversarial testing).

<a id="b"></a>

## B

- **Backdoor (модельный)** - встроенный в модель триггер, при котором по специальному входу модель выдаёт заданное поведение.
- **Bias (предвзятость)** - систематическое искажение результатов модели по отношению к определённым группам.
- **BLAST radius** - потенциальный масштаб ущерба от инцидента.
- **БФМ** - большая фундаментальная модель. В контексте 243-ФЗ от 26.07.2026 применимость определяется совокупностью признаков ст. 3 п. 2; не менее 1 млрд параметров — один из них. Квалификация модели, роли и даты применения норм проверяются отдельно. См. [18](18-ru-compliance-deep.md).

<a id="c"></a>

## C

- **Cache-membership inference** - вывод о том, обрабатывался ли выбранный prefix или объект, по наблюдаемому поведению cache. Это свойство serving state; проверка требует собственных warm/cold controls, разделения principals, нагрузки и оценки неопределённости. См. [17](17-privacy-enhancing-tech.md).
- **C2PA** - Coalition for Content Provenance and Authenticity; спецификация подписанных утверждений о происхождении и преобразованиях контента. Проверка manifest не доказывает истинность сцены, отсутствие манипуляции или правомерность использования. См. [29](29-watermarking-attribution.md).
- **CBR / акты Банка России** - нормативные и рекомендательные документы с разными предметом и кругом адресатов. В частности, 716-П относится к управлению операционным риском; номера нельзя объединять в один универсальный AI/MRM-стандарт. Применимость — в [18](18-ru-compliance-deep.md).
- **CMMI** - Capability Maturity Model Integration, модель оценки зрелости процессов.
- **Confidential Computing** - защита данных при обработке с опорой на аппаратно изолированную среду, attestation и управление ключами в определённой модели угроз. Не устраняет уязвимости доверенного кода внутри среды.
- **Corpus poisoning** - отравление корпуса RAG: внедрение вредоносных документов в базу знаний.
- **Cosign** - утилита Sigstore для подписи контейнеров и артефактов.
- **CycloneDX ML-BOM** - формат BOM с расширением для ML (ml-model, datasets).

<a id="d"></a>

## D

- **Data poisoning** - отравление обучающих данных с целью внедрить backdoor или снизить качество.
- **DDoW (Denial of Wallet)** - атака на исчерпание токен-бюджета организации.
- **Deepfake** - синтетический контент, имитирующий реальную личность.
- **DFD** - Data Flow Diagram, диаграмма потоков данных, используется в threat modeling.
- **Differential Privacy (DP)** - формальная гарантия ограниченного влияния одной единицы приватности на распределение результата механизма при заданном соседстве наборов и параметрах ε, δ. Требует учёта композиции раскрытий. См. [17](17-privacy-enhancing-tech.md).
- **Delegation** - передача ограниченных полномочий другому исполнителю с сохранением исходного субъекта, scope, срока и условий отзыва; новая цепочка не должна расширять права.
- **DLP** - Data Loss Prevention, система предотвращения утечек данных.
- **DPO** - Data Protection Officer, ответственный за обработку ПДн.
- **Drift** - изменение распределений данных или связей между входом и целевой переменной; не тождественно доказанному падению качества и само по себе не подтверждает атаку.

<a id="e"></a>

## E

- **EchoLeak** - имя конкретной zero-click prompt-injection уязвимости Microsoft 365 Copilot (CVE-2025-32711), позволявшей вывести данные из контекста через недоверенное письмо и последующие обращения. Это не общее название утечки system prompt. [Разбор исследователей](https://www.catonetworks.com/blog/breaking-down-echoleak/); применение — [25](25-prompt-ops.md).
- **Edge node** - узел распределённого LLM Gateway, обслуживающий локальный сегмент.
- **Elicitation** - запрос MCP-сервера к пользователю через host: form либо отдельный browser handoff. Consent на открытие URL не означает завершённую авторизацию или допуск бизнес-действия. См. [10](10-llm-agent-protection.md).
- **Embedding** - векторное представление текста / изображения / аудио для семантического поиска.
- **epsilon (ε)** - параметр DP, ограничивающий различимость результатов на соседних наборах; меньший ε означает более сильное ограничение при одинаковых единице приватности, соседстве, δ и механизме учёта. Числа разных протоколов нельзя сравнивать без этих условий.
- **Evidence** - проверяемое свидетельство с происхождением, временем, scope и связью с конкретной конфигурацией; наличие документа или checkbox не доказывает действие контроля.
- **Effect oracle** - независимый способ установить фактический эффект операции, например проверка записи у получателя; ответ самой модели не является достаточным подтверждением.

<a id="f"></a>

## F

- **Federated Learning** - обучение модели без централизации данных (Flower, NVFlare).
- **Fine-tuning** - дообучение предобученной модели на специализированных данных.
- **ФинЦЕРТ** - Центр мониторинга и реагирования на компьютерные атаки в кредитно-финансовой сфере ЦБ.
- **FLOP** - floating-point operation, метрика вычислительной сложности.
- **ФСБ 378 / 547** - разные приказы: применение СКЗИ при защите ПДн и порядок информирования о компьютерных атаках/инцидентах соответственно. № 367 встречается в исторических материалах; текущую процедуру и сроки сверяйте по [18](18-ru-compliance-deep.md).
- **ФСТЭК / приказы** - требования к конкретным видам систем и объектов. Применимость и переходные положения проверяются по актуальному тексту; старый номер в шаблоне не подтверждает текущую редакцию. См. [матрицу](compliance-matrices/FSTEK-ORDERS.md).

<a id="g"></a>

## G

- **Garak** - open-source фреймворк для red teaming LLM.
- **Gateway (LLM Gateway)** - посредник, на котором могут применяться authentication, policy, маршрутизация, лимиты и журналирование. Возможности зависят от реализации и покрытия маршрутов; gateway не заменяет проверку прав внутри tool executor.
- **GOSSOPKA (ГосСОПКА)** - Государственная система обнаружения, предупреждения и ликвидации последствий компьютерных атак.
- **GPAI** - General-Purpose AI, универсальные модели по EU AI Act.
- **Guardrails** - программные ограничители поведения LLM (input/output фильтры, policies).

<a id="h"></a>

## H

- **Hallucination (галлюцинация)** - вымышленное утверждение LLM, не основанное на фактах.
- **HITL** - Human In The Loop, участие человека в принятии решения; действенность требует доступа к существенной информации, времени и полномочий отклонить действие. Формальная кнопка Approve этого не подтверждает.
- **Homomorphic Encryption (HE)** - гомоморфное шифрование, позволяет вычисления над зашифрованными данными (OpenFHE, Concrete).
- **HSM** - Hardware Security Module.

<a id="i"></a>

## I

- **ISPDn** (ИСПДн) - Информационная система персональных данных.
- **IR (Incident Response)** - реагирование на инциденты.
- **ISO/IEC 42001** - стандарт AIMS (AI Management System).
- **ISO/IEC 23053** - рамка ИИ для AI/ML.
- **ISO/IEC 27001 / 27701** - ISMS / Privacy Information Management.

<a id="j"></a>

## J

- **Jailbreak** - обход safety-ограничений LLM через специально сформированные промпты.

<a id="k"></a>

## K

- **K0-K4** - внутренняя классификация данных: K0 публичные, K1 внутренние, K2 коммерческая тайна, K3 ПДн и иные охраняемые сведения по политике, K4 государственная тайна/специальный выделенный контур. Не заменяет категории ПДн, УЗ, КИИ или правовое основание. См. [02](02-stage0-ml-system-design.md).
- **Kill-switch** - механизм остановки допуска или исполнения в заданном scope. Уровни L0-L4 в методике — архитектурный пример; завершение внешних операций и отзыв уже выданных credentials проверяются отдельно.
- **KV cache / prefix cache** - переиспользование attention state уже вычисленных токенов. Совпадение prefix не разрешает доступ к чужому состоянию; namespace, модель/адаптеры, media identity и границы обмена KV проверяются отдельно. См. [05](05-stage3-model-deployment.md).
- **КИИ** - Критическая информационная инфраструктура (187-ФЗ).
- **Kubescape** - сканер конфигураций Kubernetes.
- **Kyverno** - policy engine для Kubernetes admission control.

<a id="l"></a>

## L

- **LHS (Latin Hypercube Sampling)** - метод систематического покрытия пространства запросов, применим для model extraction.
- **LLM** - Large Language Model.
- **LLM Guard** - open-source библиотека для input/output guardrails (Protect AI); заархивирована, не сопровождается.
- **LoRA** - Low-Rank Adaptation, техника эффективного fine-tuning.
- **Luhn** - алгоритм проверки контрольной цифры, используемый в том числе для платёжных карт; совпадение не доказывает существование карты или наличие ПДн.

<a id="m"></a>

## M

- **MCP (Model Context Protocol)** - протокол обмена контекстом, ресурсами и вызовами инструментов между клиентом и сервером. Авторизация транспорта не заменяет проверку допустимости конкретной операции. См. [33](33-ai-agents-security-overlay.md).
- **Membership Inference** - атака на определение, был ли конкретный пример в обучающем наборе.
- **MIG (Multi-Instance GPU)** - аппаратное разбиение поддерживаемых NVIDIA GPU на инстансы. Границы GI/CI и разделяемых ресурсов зависят от платформы; MIG не тождественен TEE или обычному time-slicing. См. [19](19-training-infrastructure.md).
- **MLflow** - open-source платформа для управления жизненным циклом ML-моделей.
- **MITRE ATLAS** - таксономия атак на ИИ-системы.
- **MITRE ATT&CK** - таксономия атак на корпоративную инфраструктуру.
- **Model card** - документированное описание модели (назначение, ограничения, метрики).
- **Model extraction** - извлечение параметров или воспроизведение существенного поведения модели; может опираться на API-запросы либо доступ к артефактам. Высокий query volume сам по себе не доказывает кражу.
- **Model inversion** - вывод свойств или реконструкция представлений чувствительных данных по доступу к модели/выводам; не всегда восстанавливает точные обучающие записи.
- **ModelScan** - инструмент сканирования моделей на вредоносный код.
- **MRM** - Model Risk Management, управление модельными рисками.
- **MRTR** - Multi-Round-Trip Requests в MCP: обмен через InputRequiredResult и возможный retry исходного метода с дополнительными inputs / state. Protocol retry не гарантирует однократного внешнего эффекта. См. [10](10-llm-agent-protection.md).

<a id="n"></a>

## N

- **НКЦКИ** - Национальный координационный центр по компьютерным инцидентам (часть ГосСОПКА).
- **NER** - Named Entity Recognition (например, в Presidio).
- **NIST AI RMF** - AI Risk Management Framework (NIST AI 100-1).
- **NIST AI 600-1** - GenAI Profile для NIST AI RMF.

<a id="o"></a>

## O

- **OPA (Open Policy Agent)** - движок вычисления policy на языке Rego. Решение OPA должен применить доверенный enforcement point; вычисленное allow само не останавливает операцию.
- **OWASP LLM Top 10** - список ключевых рисков LLM-приложений.
- **OpenFHE** - open-source библиотека FHE.

<a id="p"></a>

## P

- **PAC (Proxy Auto-Config)** - конфигурация выбора прокси клиентом. Помогает маршрутизации, но сама по себе не предотвращает прямое соединение или обход другим клиентом.
- **PET (Privacy Enhancing Technologies)** - технологии усиления приватности: DP, FL, TEE, HE.
- **PIA** - Privacy Impact Assessment, оценка влияния на приватность.
- **Pickle malware** - вредоносный код, внедрённый в pickle-файл модели.
- **Presidio** - framework для поиска и обработки ПДн под community governance Data Privacy Stack; первоначально разработан Microsoft.
- **Prompt injection** - попытка заставить систему принять недоверенный контент за управляющую инструкцию; источник может быть прямым вводом, retrieval, файлом, изображением или tool output.
- **Provider prompt cache** - провайдерский механизм повторного использования входа и его учёта. Eligible cached tokens, физическое KV reuse и задержка — отдельные наблюдения; состав usage, цена и retention зависят от модели/API. См. [22](22-finops-ai.md).
- **Privacy ledger** - учёт связанных DP-запусков и раскрытий с параметрами механизма и accountant. Перезапуск job или новый календарный квартал не обнуляет уже израсходованный бюджет.
- **PoLP** - Principle of Least Privilege.
- **Provenance** - происхождение, цепочка трансформаций данных или артефакта.
- **PSS (Pod Security Standards)** - стандарты безопасности pod в Kubernetes.
- **PyRIT** - Python Risk Identification Tool, Microsoft-овский фреймворк для red teaming LLM.

<a id="q"></a>

## Q

- **QLoRA** - Quantized LoRA, квантованная версия LoRA.
- **Qdrant** - open-source vector DB.

<a id="r"></a>

## R

- **RACI** - матрица ответственности (Responsible, Accountable, Consulted, Informed).
- **RAG** - Retrieval-Augmented Generation, генерация с извлечением контекста из базы знаний.
- **RBAC** - Role-Based Access Control.
- **RPM** - Requests Per Minute, единица rate limit.
- **RPO / RTO** - Recovery Point / Time Objective.
- **Red Teaming** - имитация атак на систему с целью выявления уязвимостей.
- **РКН** - Роскомнадзор.

<a id="s"></a>

## S

- **Sampling** - в MCP запрос сервера на генерацию через модель клиента; отдельные расходы и раскрытие данных. Feature deprecated в 2026-07-28; сам протокол имеет статус Current. См. [10](10-llm-agent-protection.md).
- **SBOM** - Software Bill of Materials.
- **Secret scanning** - поиск секретов (API keys, токены) в коде / артефактах.
- **SGX** - Software Guard Extensions, Intel TEE.
- **Sigma rules** - открытый формат правил корреляции для SIEM.
- **SIEM** - Security Information and Event Management.
- **Sigstore** - экосистема для подписи open-source артефактов (cosign, fulcio, rekor).
- **SafeTensors** - формат хранения тензоров без встроенного исполнения pickle-кода. Не доказывает отсутствие backdoor, разрешённое происхождение весов или безопасность сопутствующего кода загрузки.
- **SLO / SLA** - Service Level Objective / Agreement.
- **SLSA** - Supply-chain Levels for Software Artifacts.
- **SPDX** - стандарт SBOM, альтернативный CycloneDX.
- **STRIDE** - Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege.
- **STRIDE-AI** - расширение STRIDE для ИИ-угроз.
- **System prompt leakage** - утечка системного промпта через пользовательские запросы.

<a id="t"></a>

## T

- **TDX** - Trust Domain Extensions, Intel TEE нового поколения.
- **TEE (Trusted Execution Environment)** - доверенная среда исполнения (SGX, TDX, AMD SEV, NVIDIA CC).
- **TextAttack** - библиотека adversarial-атак на NLP-модели.
- **Tier 1–4** - внутренняя шкала критичности ИИ-системы в методике: 1 — наивысший, 4 — низкий. Назначается по сценарию и последствиям, не равна классу данных K0-K4 или категории EU AI Act. Организация закрепляет критерии и версию методики. См. [14](14-model-risk-governance.md).
- **Tombstone** - устойчивая запись об отзыве/выводе объекта из использования, проверяемая также при восстановлении из старой копии или checkpoint; сама не доказывает физическое удаление всех копий.
- **TTP** - Tactics, Techniques, Procedures.
- **Trivy / Grype / Syft** - сканеры уязвимостей и SBOM.

<a id="u"></a>

## U

- **Unknown outcome** - состояние, когда результат операции не установлен: например, внешний сервис принял запись, но ответ потерян. Требует проверки эффекта; автоматический повтор может создать дубликат.
- **УЗ (УЗ1-УЗ4)** - Уровни защищённости ИСПДн (Постановление 1119).

<a id="v"></a>

## V

- **Vector DB** - база данных для векторных embedding (Qdrant, Weaviate, pgvector, Milvus).

<a id="w"></a>

## W

- **WAF** - Web Application Firewall.
- **Watermarking** - внесение обнаруживаемого сигнала в текст, изображение, аудио или другой результат. Детектор presence, извлечение payload, устойчивость к преобразованиям и неподделываемость — разные свойства, проверяемые при заданном FPR и бюджете изменения качества. См. [29](29-watermarking-attribution.md).

<a id="x"></a>

## X

- **XGBoost** - градиентный бустинг, популярен для табличных моделей (скоринг, антифрод).

<a id="y"></a>

## Y

- **YARA** - формат правил обнаружения вредоносного ПО.

<a id="z"></a>

## Z

- **Zero-trust** - архитектурный принцип "не доверяй, проверяй".
