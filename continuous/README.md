# Continuous Content: живые материалы MLSec

> **Версия**: 1.0 · **Дата**: 2026-04-22 · **Частота обновления**: ежемесячно / по событию

Папка содержит материалы, которые обновляются регулярно (в отличие от основной документации, которая ревизится версиями). Работают как «рабочий стол» MLSec-команды.

**Статус на 2026-11-13:** ритм ниже описывает целевой процесс, а не подтверждённую историю обновлений. CVE Watch содержит историческую подборку; в Incident Log учебные сценарии явно отделены от публичных записей. У каждой проверки указывайте охват и источник: новая дата файла сама по себе не означает полноту реестра.

**Дополнение проверки 13.11.2026:** в CVE Watch добавлены два PyTorch advisory 2026 года, уточнены настройки Ray и датированный EPSS Transformers. В Incident Log добавлены три подтверждённые публикациями поставщиков записи 2026 года. Это выборочная актуализация, не полная лента угроз или инцидентов. Планы применения ниже требуют проверки собственного inventory и не означают выполненное обновление milksec.com.

<a id="pravila-raboty"></a>

## Правила работы

1. Все три файла обновляются **инкрементально**: новые записи сверху, старые не удаляются.
2. Каждая запись помечена датой и автором.
3. Ссылки на внешние источники обязательны (публикация РКН, CVE-ID, номер закона).
4. Для CVE-watch: scope охватывает фреймворки (PyTorch, TensorFlow, JAX), библиотеки (HuggingFace, LangChain, Transformers), инструменты (garak, Guardrails), инфраструктуру (Triton, Ray, Kubeflow).
5. Для incident-log: публичные инциденты индустрии, не внутренние (для внутренних: [playbooks/](../playbooks/)).
6. Для regulatory-timeline: сроки вступления в силу, deadline-ы для compliance, quarterly reminders.
7. Для advisory без подтверждённого CVE используйте GHSA-ID. Различайте дату события, дату раскрытия и дату проверки. Отделяйте подтверждённые факты поставщика от его интерпретаций и наших инженерных уроков.

<a id="ritm"></a>

## Ритм

- **Понедельник, 10:00**: MLSec Lead агрегирует CVE за неделю → cve-watch.md.
- **После события**: инцидент в индустрии → IR добавляет запись в incident-log.md в течение 48ч.
- **Первый рабочий день месяца**: Юрист обновляет regulatory-timeline.md.
- **Ежеквартально**: материалы суммируются в MLSec report в совет.
